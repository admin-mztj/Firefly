# 一级标题

段落之间用空行分隔。

第二段。*斜体*、**粗体**和`等宽字体`。列表看起来像这样：

- 这一项
- 那一项
- 另一项

请注意，撇开星号不谈，实际的文本内容从第 4 列开始。

> 引用块
> 像这样写。
>
> 如果你愿意的话，
> 可以跨越多个段落。

使用 3 个破折号表示长破折号。使用 2 个破折号表示范围（例如，"全在第 12-14 章中"）。三个点 ... 会被转换为省略号。
支持 Unicode。☺

## 二级标题

这是一个编号列表：

1. 第一项
2. 第二项
3. 第三项

再次注意实际文本从第 4 列开始（距左侧 4 个字符）。这是代码示例：

    # 让我再重复一遍...
    for i in 1 .. 10 { do-something(i) }

如你所料，缩进了 4 个空格。顺便说一句，如果你愿意的话，可以使用分隔代码块：

```
define foobar() {
    print "欢迎来到风味之国！";
}
```

（这样复制粘贴更方便）。你也可以选择标记分隔代码块让 Pandoc 进行语法高亮：

```python
import time
# 快点，数到十！
for i in range(10):
    #（但也别太快）
    time.sleep(0.5)
    print i
```

### 三级标题

现在是一个嵌套列表：

1. 首先，准备这些材料：

    - 胡萝卜
    - 芹菜
    - 扁豆

2. 烧开水。

3. 把所有东西倒进锅里，然后按照
    这个算法操作：

        找到木勺
        揭开锅盖
        搅拌
        盖上锅盖
        把木勺危险地搭在锅柄上
        等 10 分钟
        回到第一步（或者好了就关火）

    注意不要撞到木勺，否则会掉下来。

再次注意文本总是按 4 个空格缩进对齐（包括上面第 3 项的最后一行）。

这是到 [某个网站](http://foo.bar) 的链接，到 [本地文档](local-doc.html) 的链接，以及到 [当前文档中的章节标题](#二级标题) 的链接。这是脚注 [^1]。
