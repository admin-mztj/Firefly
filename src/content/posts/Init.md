# 第一幕

机缘巧合在 GitHub 浏览前辈的开源项目，受大佬启发，终于拥有了属于自己的博客。

其实搭建博客本没有什么功利的用处，我只是想找一处地方好好记录生活。人生步履匆匆，很多细碎的经历总会随着时间慢慢被遗忘，我不想多年以后回头回望，过往只剩一片空白。往后人生里的顺遂与失意、高光与遗憾，都想在这里妥善安放，让所有经历有据可查。

往后我会在这里随手落笔：或是旅途偶遇的风月、日常不起眼的琐事，或是读书工作途中沉淀的思考与收获。用零散的文字，拼凑出自己一路走来的岁岁年年。

最后送给自己也是送给各位一句话：
> [落笔当下，不负来日]()
